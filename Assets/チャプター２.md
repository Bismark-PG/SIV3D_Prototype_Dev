&nbsp;	　　言うならば我々は『真になった嘘』ですので。」

\[player]「噂で出来た情報の集合体、か。」

\[name]「はい。我々は人などから出される噂によって形を成し、力を手に入れます。

&nbsp;	　　その都市伝説の中の１体に、私たちは監禁されています。

&nbsp;	　　私はその都市伝説を倒そうと思い、貴方に協力を仰ぎました。」

\[player]「色々訊きたい事はあるけど...まずなんで僕の助けがいるんだ？」

\[name]「それは『何故私が助けを必要としているか』でしょうか。『何故人間に助けを求めたか』でしょうか。

&nbsp;	　　それとも、『何故協力者に\[player]を選んだか』？」

\[player]「まぁ大体全部かな...先２つはざっくりわかるけど...。」

\[name]「それでは簡潔に。

&nbsp;	　　①私が都市伝説として未熟だからです。都市伝説ではあるものの、まだ何者でもない、中途半端な個体なので。

&nbsp;	　　②都市伝説を育てるには人間が最適だからです。現代社会に於いては誰もが片手間で噂を取り入れ、そして発信する事が出来るようになってしまったので。

&nbsp;	　　③たまたま近くにいたあの情報に耐えうる人間が\[player]だったので。」

\[player]「たまたまかよ...その情報に耐えうるってのは何を以て判断してるんだ？」

\[name]「与える情報の受け入れやすさですね。\[player]は、都市伝説がお好きで？」

\[player]「まぁ動画とかで結構見たりはするけど...それって見て判断できるものなのか？それとも都市伝説の能力？」

\[name]「？分かりませんよ、そんなことは。\[player]が耐えうる人間じゃなければ別な人間を探していました。」

\[player]「...もし情報に耐えられなかった場合はどうなるんだ？」

\[name]「廃人になるでしょうね。」

\[player]「お前...人間を使い捨ての駒みたいに...！」

\[name]「先程も申し上げましたが、貴方(人間)の価値観を押し付けないで下さい。この世界の解放の重大さに比べればそんなことは些事でしかないですよ。」

\[player]「人の人生が些事であっていい訳がないだろ！」

\[name]「それにこの世界は解放された後恐らく攫われる前に時間に回帰しますよ。それでも貴方からすれば憤慨するようなことなのでしょうか？」

\[player]「そういうことじゃあ...

&nbsp;	　　　いや、もういい。」

\[name]「理解していただけましたか。」

\[player]「お前達とは相容れないってことがね。

&nbsp;	　　僕達の情報から出来たとはいえ、お前達は情報の上辺だけを切り取って存在しているんだ。

&nbsp;	　　だから決して理解することも無いし、されることも無いと思うよ。」

\[name]「左様ですか。私としてもお友達ごっこをするつもりなど毛頭ありません。

&nbsp;	　　そも回帰されれば無かったことになりますので、元から７日のみの交流だと思っています。」

\[player]「そうか。

&nbsp;	　　ところでその７日てのはどこから出てきた数字だ？」

\[name]「奴と戦う期限です。それ以降、奴は大成して勝算はほぼゼロに等しくなるでしょう。」

\[player]「１週間てのは大分短いが...その僕達を閉じ込めている都市伝説についての情報の仔細が欲しい。」

\[name]「はい。

&nbsp;	　　その都市伝説の名は『きさらぎ』。かつて『きさらぎ駅』という名で存在していた都市伝説です。

&nbsp;	　　近代日本においてあまりにも名のある都市伝説でしたが、それは大きくなりすぎました。

&nbsp;	　　他の類似点を持つ都市伝説の吸収を繰り返し、あまつさえ都市そのものとなった、正しく『都市』伝説です。

&nbsp;	　　それは人や動物、都市伝説を我が身の中に誘い、自分の分け身を這わせ、噂を流させることによって、現在進行形で強くなり続けています。」

\[player]「なんて厄介な...場所系の都市伝説だしこれといって弱点も思いつかないけど...。

&nbsp;	　　戦うってことは勝てる見込みはあるんだろ？」

\[name]「私と\[player]の努力次第ですね。

&nbsp;	　　私は今は未熟ではありますが、裏を返せば何者にも成れることができます。」

\[player]「成程な。それで今僕に出来る事は？」

\[name]「ありません。寝て下さい。」

\[player]「あ、はい。おやすみ。」
